# Event & Media Management Platform

## Overview

Event & Media Management Platform is a full-stack web application designed to help organizations, clubs, and communities manage events and media efficiently. The platform provides event creation, media uploads, engagement tracking, analytics, and AI-powered face recognition for personalized photo discovery.

## Features

### Authentication & Authorization

* JWT Authentication
* Role-Based Access Control
* Secure Login & Registration

### Event Management

* Create Events
* View Event Galleries
* Manage Event Information

### Media Management

* Upload Images
* Cloudinary Integration
* Media Gallery
* Delete Media

### User Engagement

* Like Media
* Comment on Media
* Engagement Tracking

### Smart Search

* Search by Tags
* Search by User Name
* Search by Upload Date

### Analytics Dashboard

* Total Events
* Total Media
* Total Likes
* Total Comments
* Most Popular Event
* Likes Per Event Chart
* Media Per Event Chart

### Watermarking

* Dynamic Watermark Downloads
* Event-Specific Watermarks

### AI Features

* Upload Selfie
* AWS Rekognition Face Matching
* Personalized "My Photos" Section
